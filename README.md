# MediConnect Android MVP

A starter Android app built with Kotlin and Jetpack Compose.

## Open it
1. Install Android Studio.
2. Choose **Open** and select the `MediConnect` folder.
3. Let Gradle sync complete.
4. Run the `app` configuration on an emulator or Android device.

## Included in this prototype
- Patient and doctor demo role switch
- Patient home dashboard
- Doctor directory and search
- Appointment request flow
- Appointment list
- Demo chat interface
- Profile screen

## Important limitations
This is a UI and interaction prototype. It uses sample data held in app memory:
- No real registration, authentication, or role authorization
- No backend or cloud database
- No real-time chat or video calling
- No payment processing or verified doctor availability
- No secure medical-record storage

Do not use this prototype to store or transmit real patient information. Before real-world clinical use, add a secure backend, strong authentication, access controls, encryption, audit logging, consent flows, privacy/legal review, and appropriate clinical safety processes.
